# FreeBuds 6i Pro (v0.1 MVP)

تطبيق Android (Kotlin + Compose) لقياس وتحسين صوت المايك وتشخيص هسيس ANC/Transparency لسماعة Huawei FreeBuds 6i على Android 11.
**لم يُبنَ ولم يُختبر على جهاز حقيقي بعد** (انظر `docs/TEST_REPORT.md`).

## الحصول على APK (بدون Android Studio)
1. أنشئ مستودعًا على GitHub وارفع محتوى هذا المجلد.
2. تبويب **Actions ← Build APK ← Run workflow** (أو يعمل تلقائيًا عند كل push).
3. بعد النجاح: افتح التشغيل ← **Artifacts ← FreeBuds6iPro-debug-apk** ← نزّل ثم فك الضغط.
4. انقل `app-debug.apk` للهاتف وثبّته (اسمح بالتثبيت من مصدر غير معروف).
بديل: افتح المجلد في Android Studio (JDK 17) ثم Build ▸ Build APK.
الـ workflow يشغّل Unit Tests أولًا؛ فشلها يوقف البناء ويعرض تقرير الاختبارات.

## البنية
- `dsp/` محرك معالجة مستقل عن الواجهة: HighPass، NoiseSuppressor+VAD، AGC، Compressor، Equalizer، Limiter، Metrics، Presets.
- `audio/` BtManager (HFP/A2DP/SCO وأحداث الاتصال)، MicRecorder (SCO أو مايك الهاتف + المصدر الفعلي)، Player.
- `data/` حفظ الملفات والنتائج محليًا (SharedPreferences + JSON)، تصدير/استيراد.
- `ui/` شاشات Compose (عربي RTL / English، فاتح/داكن حسب النظام).

## القيود المعروفة
- المعالجة Mono، 16-bit، ومحرك Kotlin فقط (بدون C++ في هذا الإصدار).
- NoiseSuppressor خوارزمية طاقة/VAD وليست تعلمًا آليًا؛ تقلل الضجيج الثابت وليس الصوت المتداخل.
- SCO على سماعات هواوي غالبًا 16 kHz أو أقل: جودة المايك محدودة بالبروتوكول نفسه.
- قياس الهسيس بمايك الهاتف نسبي ولا يمثل ما تسمعه داخل الأذن.
- لا توجد شاشة Equalizer للموسيقى ولا اختيار Profile تلقائي بعد.
- النصوص في `tr()` ثنائية اللغة؛ يمكن نقلها لـ strings.xml لاحقًا.
- Release APK يحتاج مفتاح توقيع خاص بك.

## الخصوصية
لا إنترنت (لا صلاحية INTERNET في الـ Manifest)، التسجيل في الذاكرة فقط، لا Root، لا أوامر Bluetooth غير موثقة، ولا مشاركة تلقائية.
